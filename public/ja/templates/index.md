# Markdown テンプレート

エージェントが書き、あなたが読む文書のために。各テンプレートにはエージェントへのプロンプトが付いています。書き上がったファイルを MarsDawn で開けば、何を書いたか読めます。

- [仕様書（PRD）](/ja/templates/spec/)：課題、目標、要件、フロー図、受け入れ基準。
- [フローチャート](/ja/templates/flowchart/)：Mermaid の図と、その下に書き出した各ステップ。
- [議事録](/ja/templates/meeting-notes/)：決定事項とアクションアイテム。それぞれに担当者。
