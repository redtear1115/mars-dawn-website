Mac의 부품으로 만들었습니다.

MarsDawn은 Markdown을 읽고 검토하는 Mac 네이티브 앱으로, 분할 실시간 미리보기, Mermaid 다이어그램, KaTeX 수식, 훑어보기, PDF 내보내기를 갖추고 있으며, 14일 동안 무료로 체험한 뒤 USD 4.99 한 번으로 잠금 해제할 수 있습니다.

윈도우, 탭, 메뉴, 텍스트 편집기는 모두 Mac의 것입니다. 렌더링된 페이지는 Safari의 엔진인 WebKit이 그립니다.

무슨 뜻인가요

편집

  • 소스, 분할, 미리보기 레이아웃을 키 하나로 오갑니다(⌘1, ⌘2, ⌘3).
  • 두 패널이 함께 스크롤되어, 편집 중인 문단이 계속 화면에 보입니다.
  • 편집기의 Markdown 구문 하이라이트는 미리보기 테마에 맞춰집니다.

나머지도 Mac 그대로

  • 네이티브 윈도우와 탭, 자동 저장, 버전 기록.
  • 훑어보기: Finder에서 Markdown 파일을 선택하고 스페이스 바를 누르면 다이어그램까지 포함된 미리보기가 나타납니다. 훑어보기 사용법
  • Siri와 단축어: 템플릿으로 새로운 문서를 시작하거나, 메모 수신함에 한 줄을 추가하거나, 최근 문서를 다시 열 수 있습니다.
  • 영어, 중국어(번체), 중국어(간체), 일본어, 독일어, 프랑스어, 스페인어, 한국어.

MarsDawn에서 기대할 수 있는 것

  • 내 글은 내 Mac에계정도, 동기화도, 클라우드도 없습니다.
  • 무료로 체험하고, 한 번만 구입14일 무료, 이후 USD 4.99 1회 구입. 구독이 아닙니다.
  • PDF 내보내기다이어그램, 코드 하이라이트, 세심한 페이지 나눔.
  • MarsDawn이 하지 않는 일구입 전에 알아 둘 점.
