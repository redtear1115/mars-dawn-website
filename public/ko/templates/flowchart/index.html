Mermaid 순서도 아래에 단계를 하나하나 적어 두어, 다이어그램과 글을 서로 대조할 수 있습니다. 단계를 하나 빼고, 나머지를 고쳐 달라고 에이전트에게 요청하세요. Mac에서 다이어그램이 그려지는 방식: Mac에서 Mermaid 미리보기.

템플릿

flowchart.md 다운로드

# 흐름 이름

_한 문장으로: 무엇이 들어가고 무엇이 나오는지._

## 다이어그램

```mermaid
flowchart LR
  A[첫 번째 단계] --> B[두 번째 단계]
  B --> C[세 번째 단계]
  C --> D[완료]
```

## 단계

1. **첫 번째 단계:** _누가 맡고, 다음 단계에 무엇을 넘기는지._
2. **두 번째 단계:** _…_
3. **세 번째 단계:** _…_
4. **완료:** _여기서 ‘완료’가 무슨 뜻인지._

보이는 모습

marsdawn export flowchart.md로 내보냈습니다. 무료 명령줄 도구는 다이어그램을 포함해 MarsDawn의 미리 보기와 똑같이 렌더링합니다.

에이전트에게 맡기기

https://marsdawn.southern-light.dev/ko/templates/flowchart/flowchart.md 템플릿을 사용해 [프로세스]의 흐름을 flowchart.md에 그려 주세요. 노드마다 번호 붙은 단계를 하나씩, 같은 순서로 적어 주세요. 다 쓰면 marsdawn open flowchart.md를 실행해 주세요.

PDF로 공유하기

marsdawn export flowchart.md: 다이어그램이 PDF 안에 그려집니다.

하지 않는 일

MarsDawn은 Mermaid에 적힌 대로 그립니다. 다이어그램을 손으로 배치할 수는 없고, 번호 붙은 단계와 노드를 맞춰 주지도 않습니다. Mermaid에 오류가 있으면 미리 보기에 다이어그램 대신 오류가 표시됩니다.

자주 묻는 질문

어떤 다이어그램을 쓸 수 있나요?

Mermaid가 그리는 것이라면 무엇이든 됩니다. 순서도, 시퀀스 다이어그램, 상태 다이어그램 등입니다.

왜 단계도 따로 적나요?

훑어보는 사람은 다이어그램을 보고, 확인하는 사람은 글이 필요합니다. 에이전트가 둘을 맞춰 둘 수 있습니다.

  • 회의록: 결정 사항과 실행 항목, 항목마다 담당자 한 명.
