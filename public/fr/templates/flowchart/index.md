# Modèle d’organigramme en Markdown

Un organigramme Mermaid avec les étapes détaillées en dessous, pour que le diagramme et le texte puissent se vérifier l’un l’autre. Retirez une étape, et demandez à l’agent de corriger le reste.

## Le modèle

[Télécharger flowchart.md](/fr/templates/flowchart/flowchart.md)

````
# Nom du flux

_Une phrase : ce qui entre, ce qui sort._

## Diagramme

```mermaid
flowchart LR
  A[Première étape] --> B[Deuxième étape]
  B --> C[Troisième étape]
  C --> D[Terminé]
```

## Étapes

1. **Première étape** : _qui s’en charge, et ce qu’il transmet._
2. **Deuxième étape** : _…_
3. **Troisième étape** : _…_
4. **Terminé** : _ce que « terminé » veut dire ici._
````

## À quoi il ressemble

![La première page de flowchart.md, exportée en PDF avec marsdawn export.](/assets/templates/flowchart-fr.png)

Exporté avec `marsdawn export flowchart.md`. L’outil en ligne de commande gratuit produit le même rendu que l’aperçu de MarsDawn, diagramme compris.

## Demandez à votre agent

```
Dessine le flux de [le processus] dans flowchart.md, à partir du modèle disponible à https://marsdawn.southern-light.dev/fr/templates/flowchart/flowchart.md. Une étape numérotée par nœud, dans le même ordre. Une fois que c’est écrit, lance marsdawn open flowchart.md.
```

## Le partager en PDF

`marsdawn export flowchart.md` : le diagramme est dessiné dans le PDF.

## Ce qu’il ne fait pas

MarsDawn dessine ce que dit le Mermaid. Il ne permet pas de disposer le diagramme à la main, et il ne synchronise pas les étapes numérotées avec les nœuds. Si le Mermaid contient une erreur, l’aperçu affiche l’erreur au lieu du diagramme.

## Questions

### Quels diagrammes fonctionnent ?

Tout ce que Mermaid sait dessiner : organigrammes, diagrammes de séquence, diagrammes d’états, et plus encore.

### Pourquoi écrire aussi les étapes ?

Qui survole regarde le diagramme ; qui vérifie a besoin du texte. L’agent peut garder les deux en phase.
