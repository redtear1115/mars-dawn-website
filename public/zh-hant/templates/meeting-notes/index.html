長什麼樣子

用 marsdawn export meeting-notes.md 輸出。免費的命令列工具排版和 MarsDawn 的預覽一樣。

交給 agent

用 https://marsdawn.southern-light.dev/zh-hant/templates/meeting-notes/meeting-notes.md 這份範本，把這場會議整理進 meeting-notes.md。先寫決議，一項一行；每個行動項目都要有一位負責人和日期。寫好之後執行 marsdawn open meeting-notes.md。

輸出 PDF 分享

marsdawn export meeting-notes.md 會輸出一份 PDF，可以附在會後的信裡。

做不到的事

MarsDawn 不會錄音或轉逐字稿，也不會追蹤行動項目。它只把會議記錄呈現成讀者會看到的樣子。

常見問題

勾選框能用嗎？

在預覽和 PDF 裡都會顯示成勾選框。要打勾，就在原始碼裡把 [ ] 改成 [x]。

agent 能讓會議記錄和行動項目保持一致嗎？

可以，這就是這個循環的用意：改其中一個，再請它更新其他部分。MarsDawn 讓你看到結果。
