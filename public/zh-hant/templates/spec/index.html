長什麼樣子

用 marsdawn export spec.md 輸出。免費的命令列工具排版和 MarsDawn 的預覽一樣，圖表也一起畫出來。

交給 agent

用 https://marsdawn.southern-light.dev/zh-hant/templates/spec/spec.md 這份範本，把［功能］的規格寫進 spec.md。每條需求都要有編號，流程圖和驗收條件用同樣的編號。寫好之後執行 marsdawn open spec.md。

輸出 PDF 分享

marsdawn export spec.md 會在旁邊寫出 spec.pdf，給不讀 Markdown 的人。

做不到的事

MarsDawn 會顯示規格、表格和流程圖，但不會檢查驗收條件有沒有涵蓋每一條需求。那是 agent 的工作，也要靠你讀。

常見問題

流程圖需要另外安裝什麼嗎？

不用。MarsDawn 和 marsdawn export 自己就會畫 Mermaid，離線也能畫。

可以在 MarsDawn 裡改規格嗎？

可以。它是 Markdown 編輯器，原始碼旁邊就是預覽。agent 下次讀這個檔案時，就會看到你的修改。
