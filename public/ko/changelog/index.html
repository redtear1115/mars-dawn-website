변경 내역

Mac, iPhone, iPad용 MarsDawn 앱과 무료 marsdawn 명령줄 도구에서 버전마다 바뀐 점입니다. 앱의 날짜는 해당 버전이 App Store에 출시된 날입니다.

앞으로 나올 기능은 로드맵에 있습니다.

Mac용 MarsDawn

MarsDawn 1.2.2

2026년 11월 23일

  • 파일 > ‘프린트…’와 파일 > ‘PDF로 내보내기…’를 선택하면 이제 ‘프린트 및 내보내기’ 시트가 열려 PDF를 미리 볼 수 있습니다. ‘문서’, ‘설명서’, ‘프린트물’ 중 하나를 고른 뒤 프린트하거나 PDF로 저장합니다. 프린트에서도 ‘문서’ 외의 레이아웃을 쓸 수 있습니다.
  • 수정: 자동 저장 직후 입력한 글자가 바뀔 수 있던 문제와 ‘분할’로 돌아온 직후 스크롤이 되돌아갈 수 있던 문제.
  • ‘설명서’를 고르면 ‘프린트 및 내보내기’ 시트에 표지에 들어갈 내용이 표시되고, ‘화성의 일출’ 표지 이미지도 넣을 수 있습니다. ‘프린트 및 내보내기’를 도구 막대에 추가할 수도 있습니다.

MarsDawn 1.2.1

2026년 11월 3일

  • 이제 Mac에서 JSON 및 YAML 파일을 편집 가능한 문서로 열 수 있으며, 입력할 때마다 업데이트되는 트리 미리보기가 옆에 표시됩니다. Finder의 훑어보기에서도 같은 트리 보기가 표시됩니다.
  • 이제 iPhone과 iPad에서도 MarsDawn으로 문서를 읽을 수 있습니다. 같은 Apple 계정으로 한 번의 체험과 한 번의 잠금 해제가 Mac, iPhone, iPad를 모두 포함하며, 잠금 해제 화면에도 이 내용이 표시됩니다.

MarsDawn 1.2.0

2026년 10월 27일

  • Markdown 편집기 위의 포맷 막대와 새로운 ‘포맷’ 메뉴로 볼드체(⌘B), 이탤릭체(⌘I), 취소선(⇧⌘X), 제목 H1–H6(⌥⌘1–⌥⌘6), 코드, 인용, 구분점 목록, 번호 목록, 할 일 목록, 링크(⌘K), ‘이미지…’, 표, 구분선, Mermaid 다이어그램, 수식을 넣을 수 있습니다. 포맷 막대는 기본적으로 켜져 있으며 보기 > ‘포맷 막대 가리기’ 또는 설정 > 화면 모드에서 끌 수 있습니다.
  • 보기 > 소스만 > ‘Markdown 구문 가리기’(⌘/)는 ‘소스만’ 보기에서 커서가 있는 줄은 원래 Markdown으로 두고 나머지 Markdown 기호를 가려 주며, 선택한 설정을 기억합니다.
  • 파일 > ‘클립보드에서 신규’(⌥⌘V)는 클립보드의 텍스트를 새 Markdown 문서로 엽니다. 클립보드에 AI 출력의 JSON 이스케이프 텍스트(예: \n)가 들어 있으면 읽기 쉽게 한 번 변환해 주고, 상단 바에서 이 옵션을 꺼 복사한 원문 그대로 유지할 수도 있습니다.
  • 편집기나 미리보기에서 텍스트를 선택하고 보조 클릭 메뉴의 ‘다음으로 보내기…’를 선택하면 프롬프트, 선택한 텍스트, 프로젝트 내 파일 경로(또는 파일 이름), 행 번호와 함께 Claude 또는 ChatGPT가 열립니다. 각 서비스를 처음 사용할 때는 먼저 확인을 요청하며, 선택 항목이 너무 길어 링크에 넣을 수 없으면 프롬프트를 복사해 열도록 안내합니다.
  • 편집 > ‘서식 있는 텍스트로 복사’는 선택한 블록(선택하지 않았을 때는 문서 전체)을 Mail, Pages, Google 문서, Notion에 붙여 넣을 수 있는 서식 있는 텍스트로 복사하며, 일반 텍스트 형식의 Markdown도 함께 복사합니다.
  • 도움말 > ‘명령줄 도구 및 에이전트 스킬 설치…’는 한 줄 설치 명령어와 AI 에이전트에 붙여 넣을 수 있는 안내가 담긴 윈도우를 엽니다. 윈도우 자체는 아무것도 설치하지 않습니다.
  • 파일 > ‘PDF로 내보내기…’의 저장 패널에 세 가지 선택지를 제공하는 ‘레이아웃’ 메뉴가 추가되었으며, 마지막 선택을 기억합니다: ‘표준’, ‘설명서’(front matter로 만든 표지, 페이지 번호가 있는 목차, 장마다 새 페이지에서 시작, 꼬리말의 n / N 페이지 번호, PDF 책갈피, 제본 여백), ‘프린트물’(오른쪽 메모 여백, 1페이지의 제목 머리말, ‘이름 · 날짜 · n / N’ 꼬리말, 메모 여백까지 넓어질 수 있는 넓은 표). 세 가지 모두 어떤 테마와도 함께 사용할 수 있으며, ‘프린트…’는 항상 ‘표준’을 사용합니다.
  • ‘미리보기만’ 또는 ‘분할’의 미리보기 쪽에서 ⌘F를 누르면 찾기 막대가 열립니다. ⌘G와 ⇧⌘G로 다음·이전 일치 항목을 순환하며 찾고, ⌘E로 현재 선택 부분을 검색에 사용할 수 있으며, 일치 항목은 노란색으로 강조됩니다. ‘분할’에서는 포커스가 있는 쪽을 검색합니다.
  • 물결표 하나로 감싸고 공백이 없는 텍스트(예: ~x~)는 이제 HackMD처럼 아래 첨자로 표시됩니다. 취소선을 쓰려면 물결표 두 개를 사용하세요: ~~x~~. 미리보기, ‘PDF로 내보내기’, 훑어보기에 모두 적용됩니다.
  • MarsDawn에서 더 많은 HackMD 문법도 읽을 수 있습니다: ==하이라이트==, ^위 첨자^, [TOC] 목차, =300x200 같은 이미지 크기, {%youtube %} 같은 임베드(링크로 표시).
  • 설정 > 화면 모드의 ‘단일 줄 바꿈 유지’를 켜면 소스의 각 줄 바꿈이 미리보기, ‘PDF로 내보내기’, 프린트, 훑어보기에서도 HackMD처럼 그대로 유지됩니다.
  • 다른 인코딩(예: Big5)으로 저장된 Markdown 파일은 이제 읽기 전용으로 열리며 윈도우 상단에 인코딩 바가 표시됩니다. 여기서 ‘UTF-8로 별도 저장…’을 눌러 편집 가능한 UTF-8 사본을 저장할 수 있으며, ‘PDF로 내보내기…’와 ‘프린트…’는 평소대로 작동합니다.
  • 16 MiB가 넘는 문서에서는 ‘개요’ 사이드바에 ‘제목 항목 없음’ 대신 ‘이 문서는 너무 커서 개요를 표시할 수 없습니다.’가 표시됩니다.
  • 접혀 있는 details 섹션 안의 코드 블록은 단어 수 계산에서 제외되며, 표 바로 위에 있는 각주 참조가 이제 링크로 올바르게 표시됩니다.

MarsDawn 1.1.1

2026년 10월 15일

  • 독일어, 일본어, 스페인어, 프랑스어에서는 설정 > 화면 모드 > “테마 더 받기…”의 시나리오 필터가 이제 “시나리오”라는 레이블의 팝업 메뉴로 표시되어 다섯 가지 선택 항목이 모두 들어갑니다. 영어, 한국어, 중국어에서는 계속 세그먼트 컨트롤을 사용합니다.

marsdawn 0.7.7

2026년 11월 9일. PNG 내보내기, 접을 수 있는 블록, 더 빨라진 큰 파일 내보내기.

  • marsdawn export --format png는 문서를 PNG로 내보내 렌더링을 확인할 수 있게 합니다. --width(600–2000, 기본값 1200), --appearance light|dark, --theme, 일부만 내보내는 --lines나 --heading을 지정할 수 있습니다. 높이가 8,000픽셀을 넘는 페이지는 번호가 붙은 여러 이미지로 나뉘며, 표, 코드 블록, 다이어그램 중간에서는 나뉘지 않습니다.
  • marsdawn export --details는 접을 수 있는 블록을 어떻게 인쇄할지 정합니다. 기본값인 expand는 이전처럼 모두 펼쳐 인쇄하고, as-written은 펼친 상태로 작성된 블록만 펼치고 나머지는 제목만 인쇄합니다. 두 방식 모두 제목은 삼각형 없이 굵은 한 줄로 인쇄됩니다.
  • 접을 수 있는 블록이 HackMD와 Obsidian의 작성법을 더 지원합니다. 제목이 없거나 {state="open"}이 붙은 :::spoiler, 제목 안의 Markdown, 중첩된 ::::spoiler, Obsidian의 접을 수 있는 콜아웃 > [!note]-, > [!tip]+를 지원합니다.
  • 큰 파일을 훨씬 빨리 내보냅니다. 저희 테스트에서 10MB 파일이 약 4분에서 약 74초로 줄었습니다.
  • 여러 marsdawn export를 동시에 실행하면 가끔 하나가 코드 5로 종료되었습니다. 이제는 자동으로 다시 시도합니다.
  • MarsDawn 앱이 실행 중이 아닐 때 여러 marsdawn open을 동시에 실행해도 이제 모든 파일이 열립니다. 이전에는 성공했다고 알려도 열리지 않는 파일이 있었습니다.

2026년 10월 22일. 프린트물 레이아웃.

marsdawn 0.7.2

2026년 10월 20일. 설명서 레이아웃, 콜아웃, 일본어 글꼴.

  • --layout의 값이 handbook으로 바뀌었습니다. 앱의 설명서(Handbook) 레이아웃과 같은 이름입니다: marsdawn export --layout handbook. --layout manual도 쓸 수 있지만 더 이상 권장하지 않습니다.
  • 미리보기와 내보낸 PDF 모두에서 콜아웃을 표시합니다. GitHub 알림(> [!NOTE], > [!WARNING] 등)과 HackMD 컨테이너(:::info, :::warning 등)를 지원합니다. :::spoiler는 접을 수 있는 섹션이 됩니다.
  • 일본어 문서는 가나와 한자에 일본어 글꼴을 씁니다. 언어는 front matter의 lang: ja에서, 없으면 본문의 가나 비율로 판단합니다.
  • 터미널에서 export나 open이 성공한 뒤, 에이전트 스킬이 설치되어 있지 않거나 오래된 버전이면 stderr에 안내를 한 번 표시합니다. stdout과 --json 출력은 바뀌지 않습니다. MARSDAWN_NO_SKILL_HINT=1로 설정하면 표시하지 않습니다.

marsdawn 0.7.1

2026년 10월 20일. 설명서 레이아웃과 파일 크기 상한.

  • marsdawn export --layout manual은 설명서로 내보냅니다. 여백을 넓히고 제본 쪽에 25mm를 남기며, 최상위 제목마다 새 페이지에서 시작합니다. front matter의 title, subtitle, version, date, author, logo로 만든 표지, 1·2단계 제목을 페이지 번호와 함께 나열한 목차, n / N 페이지 번호, PDF 책갈피도 들어갑니다. 목차 페이지의 제목은 --toc-title로 정합니다. 기본값은 여전히 --layout document입니다.
  • 한 줄에 단독으로 쓴 <!--BREAK-->는 새 페이지를 시작합니다. 두 레이아웃 모두 해당합니다.
  • marsdawn export는 16MiB를 넘는 파일을 처리하지 않습니다. 코드 5로 종료하고, --json에서는 input_too_large를 알리며, 아무것도 쓰지 않습니다.
  • 미리보기 페이지는 script와 noscript 요소를 없앱니다. Mermaid 다이어그램을 다시 그릴 때는 그 다이어그램의 SVG를 유지합니다.
  • 디코딩하면 =나 ^가 되는 문자 참조(예: &#61;)는 더 이상 HackMD 표시와 짝을 이루지 않습니다.

marsdawn 0.7.0

2026년 10월 18일. HackMD 문법, 줄바꿈, 아주 큰 문서의 상한.

  • HackMD의 인라인 표시 ==mark==, ^sup^, ~sub~를 렌더링합니다. [TOC]만 있는 문단은 목차가 되고, HackMD 방식의 이미지 크기가 적용되며, 임베드 태그는 일반 https 링크가 됩니다. 코드 펜스의 언어는 js= 같은 HackMD 옵션보다 먼저 읽습니다.
  • marsdawn export --breaks는 HackMD처럼 문단 안의 모든 줄바꿈을 줄바꿈으로 표시합니다. 주지 않으면 중국어나 일본어 글자 두 개 사이의 줄바꿈은 없어져 앞뒤 줄이 한 문장으로 이어집니다. 한국어는 단어를 띄어 쓰므로 공백을 유지합니다.
  • 아주 큰 문서에는 미리보기와 내보낸 PDF 모두에 상한이 있습니다. 128K자를 넘는 코드 블록은 구문 강조를 하지 않고, 합계 256K자를 넘으면 구문 강조를 멈춥니다. 한 번 업데이트할 때 Mermaid 다이어그램은 100개, 수식은 1,000개까지 렌더링합니다. 나머지 다이어그램은 전에 그린 적이 있더라도 안내와 함께 소스를 보여 줍니다.
  • 시퀀스 다이어그램에서 rect 블록 안의 메시지 레이블 둘레가 그 블록의 색이 됩니다.
  • 표 바로 위에 각주 참조가 있어도 marsdawn export가 더 이상 비정상 종료되지 않습니다.
  • marsdawn skill --install은 폴더를 만들 수 없거나 파일을 쓸 수 없을 때 코드 7(skill_install_failed)로 종료합니다. 기존 SKILL.md는 그대로 둡니다.

marsdawn 0.6.4

2026년 10월 13일. 접을 수 있는 <details> 블록.

  • PDF로 내보낼 때는 인쇄하기 전에 모든 <details> 블록을 펼칩니다(front matter 제외).
  • <details> 블록을 펼치거나 접어도 미리보기의 스크롤 위치가 그대로 유지됩니다.

marsdawn 0.6.3

2026년 10월 6일. MarsDawn이 Mac App Store에 출시되었습니다.

  • 앱이 설치되어 있지 않으면 marsdawn open이 Mac App Store의 MarsDawn을 안내합니다.

marsdawn 0.6.1

2026년 9월 29일. 테마 확인.

  • marsdawn theme validate는 앱과 같은 규칙으로 theme.json을 확인합니다. 테마가 올바르면 코드 0, 아니면 코드 1로 종료하며 문제를 하나씩 보여 줍니다. --require-complete를 주면 구문 강조와 다이어그램 색상도 요구합니다.

marsdawn 0.5.4

2026년 9월 26일. Mermaid 수정, 다이어그램 오류의 줄 번호, 스킬 설치.

  • 시퀀스 다이어그램에서 다른 참여자의 생명선을 가로지르는 메시지 레이블이 미리보기와 내보낸 PDF 모두에서 읽기 쉽게 유지됩니다.
  • marsdawn export가 Mermaid 다이어그램이 가득한 문서도 처리합니다. 예전에는 종료 코드 5로 실패하던 다이어그램 50개짜리 문서도 이제 내보내집니다.
  • marsdawn export --json에 diagramErrorDetails가 추가되어 다이어그램 오류마다 줄 번호를 알려줍니다. 문서에서 다이어그램이 시작하는 위치와, Mermaid가 지목하는 경우 오류가 난 줄 자체입니다.
  • marsdawn skill --install은 Claude Code용 에이전트 스킬을 ~/.claude/skills/marsdawn/SKILL.md에, 또는 --dir로 지정한 다른 폴더에 설치합니다. 같은 파일이 있으면 그대로 두고, 다른 파일은 --force를 줄 때만 바꿉니다. 그렇지 않으면 종료 코드 64(skill_differs)로 끝나며 아무것도 바꾸지 않습니다.

marsdawn 0.5.3

2026년 9월 25일. 폴더 상태, Mermaid 오류 전문, 작은 수정들.

  • marsdawn open --folder가 폴더에 어떤 일이 있었는지 알려줄 수 있습니다. 응답을 보내는 앱이라면 최대 --wait초(기본값 2초) 동안 기다리고, --json은 attached나 needsUser 같은 상태를 돌려줍니다.

  • 프런트 매터 블록의 끝을 찾는 검색이 1,000줄에서 멈추므로, 닫히지 않은 블록 때문에 큰 문서의 나머지를 끝까지 훑는 일이 더는 없습니다.
  • 앱이 PDF 내보내기와 프린트용으로 각주 되돌아가기 링크에 번역된 레이블을 붙일 수 있습니다. 이 레이블은 페이지에 인쇄되지 않으며, marsdawn export는 영어 레이블을 유지합니다.
  • 함께 들어 있는 highlight.js가 이제 KaTeX, Mermaid처럼 버전, 출처, SHA-256으로 고정됩니다.
