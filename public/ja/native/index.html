Mac 自身のパーツで作られています。

MarsDawn は、Markdown を読んで確かめるための Mac ネイティブアプリです。分割ライブプレビュー、Mermaid の図、KaTeX の数式、クイックルック、PDF 書き出しに対応し、14 日間無料で試せて、一度だけ USD 4.99 で解除できます。Mac では JSON と YAML もツリープレビュー付きで開けます。

ウインドウ、タブ、メニュー、テキストエディタはすべて Mac 自身のものです。レンダリングされたページは、Safari を動かしているエンジンである WebKit が描画します。

それが意味すること

編集

  • ソース、分割、プレビューの3つのレイアウトを、キー1つで切り替え（⌘1、⌘2、⌘3）。
  • 2つのペインは一緒にスクロールするので、編集中の段落が常に見えています。
  • エディタの Markdown シンタックスハイライトは、プレビューのテーマに合わせられます。

Mac のほかの部分と

  • ネイティブなウインドウ、タブ、自動保存、バージョン履歴。
  • クイックルック：Finder で Markdown ファイルを選んでスペースキーを押すとプレビューでき、図も表示されます。クイックルックの使い方
  • Siri とショートカット：テンプレートから新しい文書を作成する、メモの受信トレイに1行追加する、最近使った文書を再度開く、といった操作ができます。
  • 英語、繁体字中国語、簡体字中国語、日本語、ドイツ語、フランス語、スペイン語、韓国語に対応。

MarsDawn に期待できること

  • あなたの文章は Mac に残りますアカウント不要、同期なし、クラウドなし。
  • 無料で試して、一度だけ購入14日間無料、その後は一度だけ USD 4.99。サブスクリプションはありません。
  • PDF 書き出し図表、コードのハイライト、配慮された改ページ。
  • MarsDawn ができないこと購入前に知っておくこと。
