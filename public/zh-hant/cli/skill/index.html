讓 agent 把寫好的文件拿給你看，也幫你做出 PDF。

這個 skill 是一個 Markdown 檔案。它教寫程式的 agent 把自己寫的文件在 MarsDawn 裡打開給你審閱，也教它安裝 marsdawn、確認它能用、把文件匯出成 PDF 並讀懂結果。

一個 Markdown 檔案，放在 ~/.claude/skills/marsdawn/SKILL.md。有了它，你的 agent 會安裝 marsdawn、輸出 PDF 並讀懂 JSON 結果；執行任何指令之前，它還是會先問你。

在 Claude Code 中安裝

命令列工具 marsdawn 會幫你寫好這個 skill，寫進去的內容和你已安裝的 marsdawn 版本相符。如果還沒有 marsdawn，先用 Homebrew 安裝：

brew install redtear1115/tap/marsdawn

然後安裝 skill：

marsdawn skill --install

這會把 skill 寫到 ~/.claude/skills/marsdawn/SKILL.md，資料夾不存在時會一併建立。因為檔案是由你手上的 marsdawn 產生的，裡面不會出現你這個版本沒有的選項。

需要做出 PDF，或寫好、改好一份要給你讀的 Markdown 文件時，Claude Code 會自動載入它，你也可以用 /marsdawn 自己執行。想先看內容的話，它只是一個簡短的檔案。

升級 marsdawn 之後

Homebrew 會升級 marsdawn，但不會動 skill，所以它會停在舊版本，要自己更新：

marsdawn skill --install --force

--force 會取代現有的 SKILL.md，包括你自己改過的地方。不加 --force 的話，如果那裡已經有內容不同的 SKILL.md，marsdawn 不會動它，會告訴你內容不同，並以代碼 64（skill_differs）結束。檔案已經是最新的，就什麼都不改。

給其他 agent

加上 --dir，指到你的 agent 放 skill 的資料夾，marsdawn 就會把 SKILL.md 寫到那裡：

marsdawn skill --install --dir <path>

這個檔案是純 Markdown，只有說明和指令，會讀指令檔的 agent 可以直接用。

沒有 Homebrew，或沒有命令列工具

如果沒辦法先安裝 marsdawn，就直接下載這個檔案：

mkdir -p ~/.claude/skills/marsdawn
curl -fsSL https://marsdawn.southern-light.dev/cli/skill/SKILL.md -o ~/.claude/skills/marsdawn/SKILL.md

這會從本站抓最新的 skill，可能比較舊的 marsdawn 還新。等你裝好命令列工具，再執行 marsdawn skill --install --force，就會換成和它相符的版本。你也可以讓 agent 讀這個網址，或直接貼給它。這個檔案是英文的。

它教什麼

  • 如果沒有 marsdawn，就用 Homebrew 安裝，再用 marsdawn --version 確認版本，而不是假設某個版本。
  • 用 marsdawn export … --json 匯出，並讀懂結果：PDF 存到哪裡、有幾頁，以及有沒有 Mermaid 圖表沒畫出來。
  • 依結束代碼分辨失敗的原因：找不到檔案、PDF 已經存在、匯出失敗、選項錯誤。
  • 用 marsdawn open file.md:行號 打開自己寫的文件，停在第一處修改，而且只開一次：之後的修改會自己出現在已開啟的視窗裡。
  • 如果沒有安裝 MarsDawn app，就告訴你一次然後繼續，不會一直重試。絕不用 open 來做 PDF。
  • 使用 --folder（marsdawn 0.5.1 以上）時，把資料夾回報為「已要求顯示」，而不是「已顯示」：由 app 決定，也不會有結果回報。

它不會做的事

  • 它不會自己取得執行任何東西的權限。你的 agent 在安裝或執行 marsdawn 之前，仍然會先問你，就像執行其他指令一樣。
  • 它不會把你的文件傳到任何地方。marsdawn 在你的 Mac 上產生 PDF，除非你加上 --allow-remote-images，否則不會載入網路上的圖片。

完整的規格，每個欄位和每個代碼，都在給 AI agent 的 marsdawn 參考裡。如果你的 agent 是透過 MCP 呼叫工具，而不是讀 skill 檔案，也可以用MCP 伺服器。
