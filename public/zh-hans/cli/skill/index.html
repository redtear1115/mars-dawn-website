让代理把写好的文稿拿给你看，也帮你做出 PDF。

这个 skill 是一个 Markdown 文件。它教写程序的代理把自己写的文稿在 MarsDawn 里打开给你审阅，也教它安装 marsdawn、确认它能用、把文稿导出成 PDF 并读懂结果。

一个 Markdown 文件，放在 ~/.claude/skills/marsdawn/SKILL.md。有了它，你的代理会安装 marsdawn、导出 PDF 并读懂 JSON 结果；运行任何命令之前，它还是会先问你。

在 Claude Code 中安装

命令行工具 marsdawn 会帮你写好这个 skill，写进去的内容和你已安装的 marsdawn 版本相符。如果还没有 marsdawn，先用 Homebrew 安装：

brew install redtear1115/tap/marsdawn

然后安装 skill：

marsdawn skill --install

这会把 skill 写到 ~/.claude/skills/marsdawn/SKILL.md，文件夹不存在时会一并创建。因为文件是由你手上的 marsdawn 生成的，里面不会出现你这个版本没有的选项。

需要做出 PDF，或写好、改好一份要给你读的 Markdown 文稿时，Claude Code 会自动加载它，你也可以用 /marsdawn 自己运行。想先看内容的话，它只是一个简短的文件。

升级 marsdawn 之后

Homebrew 会升级 marsdawn，但不会动 skill，所以它会停在旧版本，要自己更新：

marsdawn skill --install --force

--force 会替换现有的 SKILL.md，包括你自己改过的地方。不加 --force 的话，如果那里已经有内容不同的 SKILL.md，marsdawn 不会动它，会告诉你内容不同，并以代码 64（skill_differs）退出。文件已经是最新的，就什么都不改。

给其他代理

加上 --dir，指到你的代理放 skill 的文件夹，marsdawn 就会把 SKILL.md 写到那里：

marsdawn skill --install --dir <path>

这个文件是纯 Markdown，只有说明和命令，会读指令文件的代理可以直接用。

没有 Homebrew，或没有命令行工具

如果没办法先安装 marsdawn，就直接下载这个文件：

mkdir -p ~/.claude/skills/marsdawn
curl -fsSL https://marsdawn.southern-light.dev/cli/skill/SKILL.md -o ~/.claude/skills/marsdawn/SKILL.md

这会从本站抓最新的 skill，可能比较旧的 marsdawn 还新。等你装好命令行工具，再执行 marsdawn skill --install --force，就会换成和它相符的版本。你也可以让代理读这个网址，或直接贴给它。这个文件是英文的。

它教什么

  • 如果没有 marsdawn，就用 Homebrew 安装，再用 marsdawn --version 确认版本，而不是假设某个版本。
  • 用 marsdawn export … --json 导出，并读懂结果：PDF 存到哪里、有几页，以及有没有 Mermaid 图表没画出来。
  • 依退出代码分辨失败的原因：找不到文件、PDF 已经存在、导出失败、选项错误。
  • 用 marsdawn open file.md:行号 打开自己写的文稿，停在第一处修改，而且只打开一次：之后的修改会自己出现在已打开的窗口里。
  • 如果没有安装 MarsDawn app，就告诉你一次然后继续，不会一直重试。绝不用 open 来做 PDF。
  • 使用 --folder（marsdawn 0.5.1 以上）时，把文件夹报告为“已请求显示”，而不是“已显示”：由 app 决定，也不会有结果返回。

它不会做的事

  • 它不会自己取得运行任何东西的权限。你的代理在安装或运行 marsdawn 之前，仍然会先问你，就像运行其他命令一样。
  • 它不会把你的文稿传到任何地方。marsdawn 在你的 Mac 上产生 PDF，除非你加上 --allow-remote-images，否则不会加载网络上的图片。

完整的规格，每个字段和每个代码，都在给 AI 代理的 marsdawn 参考里。
