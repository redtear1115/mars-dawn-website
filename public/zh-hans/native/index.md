# 用 Mac 原生的组件做的。

窗口、标签页、菜单和文本编辑器都是 Mac 原生的。排版后的页面由 Safari 使用的 WebKit 引擎绘制。

![MarsDawn 的并排布局：左边是 Markdown 源代码，右边是排版后的页面。](https://marsdawn.southern-light.dev/assets/screens/01-split-1180.png)

这张截图里：

1. 原生的 Mac 窗口。
2. Mac 原生的文本编辑器，附 Markdown 语法高亮。
3. ⌘1 源代码、⌘2 并排、⌘3 预览。
4. 页面会随着打字更新。

## 这代表什么

- 源代码、并排、预览三种布局，一个快捷键切换（`⌘1`、`⌘2`、`⌘3`）。
- 两侧同步滚动，正在编辑的段落一直在眼前。
- 编辑器内置 Markdown 语法高亮，颜色与预览主题一致。
- 原生窗口、标签页、自动保存和版本记录。
- 快速查看：在 Finder 选取 Markdown 文件按空格键就能预览，图表也会显示。
- Siri 和快捷指令：用模板添加文稿、在笔记收件箱加上一行，或重新打开最近的文稿。
- 支持英文、繁体中文、简体中文和日文。
