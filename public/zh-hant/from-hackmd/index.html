從 HackMD 搬到 Mac

你的筆記本來就是 Markdown，不用轉檔。看你要搬多少，選一條路。圖片要另外處理，刪 HackMD 上的東西之前，請先讀「圖片」那段。

這頁是 2026 年 11 月用 HackMD 免費帳號實測的。HackMD 可能會變，付費方案和團隊工作區我們沒測。

你想要走這條
搬全部筆記下載所有筆記
搬已經在 GitHub 的筆記clone repo
搬一兩篇下載單篇

下載所有筆記

HackMD 的筆記設定裡有「下載所有筆記」，個人和團隊空間都有。下載下來是一個 .zip，一篇筆記一個 .md，檔名是筆記標題。

  • 資料夾不會保留，所有筆記都在最上層。
  • 圖片不在裡面，.md 裡仍然是網址。
  • 「包含標題和標籤」預設打開，會在每篇最前面加一段 front matter。關掉就和筆記原文相同。

解壓縮後，在 MarsDawn 選「檔案 ▸ 打開資料夾⋯」打開那個資料夾。

clone repo

HackMD 的 GitHub 同步是一篇筆記對一個檔案，所以推送過的筆記已經在 repo 裡。clone 下來，用「檔案 ▸ 打開資料夾⋯」打開，側邊欄會顯示 repo 和分支。

還沒接 GitHub 的筆記，不用為了搬家特地接。每篇都要各自綁定，免費版每月可以推送 20 次。在免費個人帳號上，我們沒看到一次推送整個工作區的入口。

搬完之後，以 repo 為正本。從 HackMD 推送會直接蓋掉 GitHub 上的內容，就算 GitHub 比較新也一樣，而且不會警告。

下載單篇

筆記選單可以下載 .md 或 .html。選 .md，再用 MarsDawn 打開。

圖片

上傳到 HackMD 的圖片，網址是 https://hackmd.io/_uploads/...。誰看得到，跟著筆記的權限走。

你的筆記是搬到 Mac 後怎麼處理
公開圖片從 HackMD 載入在預覽按「載入圖片」，或打開「設定 ▸ 圖片 ▸ 自動載入網路圖片」
私人圖片會回錯誤，因為 MarsDawn 沒有登入 HackMD在登入的瀏覽器把圖片存下來，放在 .md 旁邊，再改路徑。或把筆記改成公開，前提是所有人都可以看
  • 舊筆記 的圖片可能是 i.imgur.com 網址。
  • 刪筆記，圖片也會失效。 網址之後打不開，所以先搬好圖片再刪。

如果 MarsDawn 讀不到檔案旁邊的圖片，用預覽裡的按鈕授權那個資料夾。

讀起來的樣子

HackMD 的語法大多照樣能讀：==螢光==、^上標^、~下標~、[TOC]、=300x200 這類圖片尺寸、Mermaid 和 KaTeX。{%youtube %} 會顯示成連結。想和 HackMD 一樣保留每個換行，請打開「設定 ▸ 外觀 ▸ 保留單一換行」。

::: 區塊也看得到。:::info、:::success、:::warning、:::danger 會顯示成有色條的區塊，上面有標題，預設是附註、提示、警告、小心；在名稱後面自己寫標題的話，就用你寫的。:::spoiler 會顯示成點一下才展開的可收合區塊。其他名稱的 ::: 區塊，或少了結尾 ::: 的，會照原文顯示。

有幾個地方不一樣：

  • ++底線++ 和 :sparkles: 這類 emoji 代碼會照原文顯示。
  • {%hackmd id %} 不會展開。
  • <i class="fa ..."> 圖示不會出現。

給腳本用：hackmd-cli

hackmd-cli 沒有一次匯出全部的指令。它一次匯出一篇，內容印在畫面上，所以要先列出筆記，再逐篇跑迴圈。你需要 Node.js、jq，以及在 HackMD 設定頁建立的 API token。不需要腳本的話，「下載所有筆記」比較簡單。

npm install -g @hackmd/hackmd-cli
export HMD_API_ACCESS_TOKEN=<你的 token>
hackmd-cli notes --output json | jq -r '.[].id' | while read -r id; do
  hackmd-cli export --noteId="$id" > "$id.md"
done
  • 資料夾帶不過來。 筆記清單沒有寫筆記在哪個資料夾，所以檔案都會放在同一層。
  • 圖片仍是 hackmd.io 連結。 請照上面「圖片」那段處理。
  • 檔名是筆記 ID， 不是標題。
  • 免費版每 30 天可以呼叫 API 400 次。 列清單 1 次，每篇筆記再 1 次。

我們只在筆記很少的帳號上試過，不知道清單很長時會怎樣。用完請到 HackMD 設定頁刪掉 token。

一起寫的話

MarsDawn 沒有多人同時編輯。需要共筆的話，繼續用 HackMD。團隊把文件放在 git 的話，每個人都能用自己的 MarsDawn 打開同一個 repo，一起完成同一份文件。請看團隊用 git 一起審文件。

常見問題

可以一次下載全部 HackMD 筆記嗎？

可以。「下載所有筆記」會給你一個 .zip，裡面都是 .md。資料夾不會保留，也不含圖片。

為什麼在 MarsDawn 看不到圖片？

MarsDawn 預設不載入網路圖片，要按「載入圖片」。如果是私人筆記，圖片載不到，請存到檔案旁邊。

一定要離開 HackMD 嗎？

不用。要一起寫，HackMD 還是比較好的選擇。MarsDawn 是讓你在 Mac 上讀和審。
