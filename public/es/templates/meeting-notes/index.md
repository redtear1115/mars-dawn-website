# Plantilla de minuta de reunión en Markdown

Primero las decisiones, luego las tareas, cada una con un responsable. Deja que tu agente redacte la minuta a partir de la transcripción, y léela antes de enviarla. Cuando cambie una decisión, pídele al agente que ajuste las tareas.

## La plantilla

[Descargar meeting-notes.md](/es/templates/meeting-notes/meeting-notes.md)

```
# Nombre de la reunión, fecha

Asistentes: _nombres_

## Decisiones

- _Qué se decidió, una por línea._

## Tareas

- [ ] Nombre: _qué y para cuándo._
- [ ] Nombre: _qué y para cuándo._

## Notas

- _Todo lo que valga la pena conservar y no sea una decisión ni una tarea._
```

## Cómo se ve

![La primera página de meeting-notes.md, exportada a PDF con marsdawn export.](/assets/templates/meeting-notes-es.png)

Exportada con `marsdawn export meeting-notes.md`. La herramienta de línea de comandos gratuita renderiza igual que la vista previa de MarsDawn.

## Pídeselo a tu agente

```
Redacta la minuta de esta reunión en meeting-notes.md, usando la plantilla de https://marsdawn.southern-light.dev/es/templates/meeting-notes/meeting-notes.md. Primero las decisiones, una por línea; cada tarea lleva un solo responsable y una fecha. Cuando esté escrita, ejecuta marsdawn open meeting-notes.md.
```

## Compártela en PDF

`marsdawn export meeting-notes.md` escribe un PDF que puedes adjuntar al correo de seguimiento.

## Lo que no hace

MarsDawn no graba ni transcribe la reunión, y no hace seguimiento de las tareas. Muestra la minuta tal como se va a leer.

## Preguntas

### ¿Funcionan las casillas de verificación?

Se muestran como casillas en la vista previa y en el PDF. Para marcar una, cambia `[ ]` por `[x]` en el código fuente.

### ¿Puede el agente mantener la minuta y las tareas al día?

Sí, ese es el sentido del ciclo: cambia una cosa y pídele que actualice el resto. MarsDawn te muestra el resultado.
