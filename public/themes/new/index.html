Build a theme

Pick a palette and a few style options below. The sample document on the right updates as you go, in light and dark, and every check the gallery's CI runs shows up here too — so a theme that reaches the submission issue has usually already passed.

You'll need a GitHub account to submit. No install, no git required for this page itself.

An AI agent can write the theme file for you: see make a theme with your agent, then open the link it gives you here to tune it.
