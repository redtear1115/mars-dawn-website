主題庫

社群投稿的預覽主題，每一個都經過開發者審核、合併後才會出現在這裡。依情境篩選，或是在瀏覽器裡打造一個自己的主題——不用安裝，也不用 git。

  • Dracula v1.0.0 經典吸血鬼深色調色盤，白日則用 Alucard 版本 — 改編自 Dracula Theme，為可讀性調整 技術文件 審閱代理產出 作者： Southern Light 版權與授權
  • Gruvbox v1.0.0 溫暖復古的米色、棕色與橘色調色盤 — 改編自 Gruvbox，為可讀性調整 技術文件 筆記分享 作者： Southern Light 版權與授權
  • Guide v1.0.0 冷白背景搭配海軍藍標題與清亮藍色連結，字級加大，適合使用者指南、教學與 README 技術文件 作者： Southern Light
  • Ledger v1.0.0 米白紙面、深綠分隔線與實心表頭，適合預算、對帳單與估價單 正式輸出 作者： Southern Light
  • Nord v1.0.0 北歐冰藍色調，並原創搭配一款淺色版本 — 改編自 Nord，為可讀性調整 技術文件 審閱代理產出 作者： Southern Light 版權與授權
  • Solarized v1.0.0 Ethan Schoonover 設計的藍綠與金色精準色盤 — 改編自 Solarized，為可讀性調整 技術文件 審閱代理產出 作者： Southern Light 版權與授權
  • Spec v1.0.0 白底正文搭配單一磚紅強調色，決策與風險以陶土色面板呈現，適合 PRD 與 RFC 審閱代理產出 正式輸出 作者： Southern Light
  • Story v1.0.0 亮色便利貼、圓角外觀與鮮明任務勾選框，適合使用者故事與衝刺筆記 筆記分享 審閱代理產出 作者： Southern Light

版權與授權

Dracula、Nord、Gruvbox 與 Solarized 改編自開放原始碼的配色專案；每個專案的版權聲明與完整授權條文請見第三方授權聲明。

主題有問題嗎？

用主題卡片上的「檢舉」按鈕（需要 JavaScript），或直接寫信到 support@southern-light.dev，附上主題名稱和版本——不論有沒有 JavaScript 都可以。檢舉會有人親自審核，確認屬實的主題會在一天內下架。
