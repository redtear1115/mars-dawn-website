변경 내역

Mac App Store의 MarsDawn 앱과 무료 marsdawn 명령줄 도구에서 버전마다 바뀐 점입니다. 앱의 날짜는 해당 버전이 Mac App Store에 출시된 날입니다.

앞으로 나올 기능은 로드맵에 있습니다.

MarsDawn 앱

MarsDawn 1.1.1

2026년 10월 15일

  • 독일어, 일본어, 스페인어, 프랑스어에서는 설정 > 화면 모드 > “테마 더 받기…”의 시나리오 필터가 이제 “시나리오”라는 레이블의 팝업 메뉴로 표시되어 다섯 가지 선택 항목이 모두 들어갑니다. 영어, 한국어, 중국어에서는 계속 세그먼트 컨트롤을 사용합니다.
  • 테마가 갤러리에서 철회되면 “테마 더 받기…”의 알림에 이제 내부 ID 대신 테마 이름(예: Inkwell Ivory)이 표시됩니다.
  • GitHub 방식으로 작성한 접을 수 있는 details 섹션이 이제 미리보기와 훑어보기에서 요약이 보이는 접힌 상태로 시작하며, 클릭하면 펼쳐집니다. PDF로 내보내기는 여전히 모든 섹션의 내용을 인쇄합니다.
  • Finder, Dock, 파일 > “열기…” 또는 marsdawn open 명령으로 연 문서가 이제 맨 앞 윈도우의 탭으로 열리며, 새 문서도 마찬가지입니다. 이전 방식을 유지하려면 설정 > 화면 모드에서 “시스템 설정 따르기”를 선택하세요.

이전 버전의 설명은 영어로만 제공됩니다. 영어 변경 내역 보기

marsdawn 명령줄 도구

0.5.1 이전 버전은 싣지 않았습니다.

marsdawn 0.7.2

2026년 10월 20일. 설명서 레이아웃, 콜아웃, 일본어 글꼴.

  • --layout의 값이 handbook으로 바뀌었습니다. 앱의 설명서(Handbook) 레이아웃과 같은 이름입니다: marsdawn export --layout handbook. --layout manual도 쓸 수 있지만 더 이상 권장하지 않습니다.
  • 미리보기와 내보낸 PDF 모두에서 콜아웃을 표시합니다. GitHub 알림(> [!NOTE], > [!WARNING] 등)과 HackMD 컨테이너(:::info, :::warning 등)를 지원합니다. :::spoiler는 접을 수 있는 섹션이 됩니다.
  • 일본어 문서는 가나와 한자에 일본어 글꼴을 씁니다. 언어는 front matter의 lang: ja에서, 없으면 본문의 가나 비율로 판단합니다.
  • 터미널에서 export나 open이 성공한 뒤, 에이전트 스킬이 설치되어 있지 않거나 오래된 버전이면 stderr에 안내를 한 번 표시합니다. stdout과 --json 출력은 바뀌지 않습니다. MARSDAWN_NO_SKILL_HINT=1로 설정하면 표시하지 않습니다.

marsdawn 0.7.1

2026년 10월 20일. 설명서 레이아웃과 파일 크기 상한.

  • marsdawn export --layout manual은 설명서로 내보냅니다. 여백을 넓히고 제본 쪽에 25mm를 남기며, 최상위 제목마다 새 페이지에서 시작합니다. front matter의 title, subtitle, version, date, author, logo로 만든 표지, 1·2단계 제목을 페이지 번호와 함께 나열한 목차, n / N 페이지 번호, PDF 책갈피도 들어갑니다. 목차 페이지의 제목은 --toc-title로 정합니다. 기본값은 여전히 --layout document입니다.
  • 한 줄에 단독으로 쓴 <!--BREAK-->는 새 페이지를 시작합니다. 두 레이아웃 모두 해당합니다.
  • marsdawn export는 16MiB를 넘는 파일을 처리하지 않습니다. 코드 5로 종료하고, --json에서는 input_too_large를 알리며, 아무것도 쓰지 않습니다.
  • 미리보기 페이지는 script와 noscript 요소를 없앱니다. Mermaid 다이어그램을 다시 그릴 때는 그 다이어그램의 SVG를 유지합니다.
  • 디코딩하면 =나 ^가 되는 문자 참조(예: &#61;)는 더 이상 HackMD 표시와 짝을 이루지 않습니다.

marsdawn 0.7.0

2026년 10월 18일. HackMD 문법, 줄바꿈, 아주 큰 문서의 상한.

  • HackMD의 인라인 표시 ==mark==, ^sup^, ~sub~를 렌더링합니다. [TOC]만 있는 문단은 목차가 되고, HackMD 방식의 이미지 크기가 적용되며, 임베드 태그는 일반 https 링크가 됩니다. 코드 펜스의 언어는 js= 같은 HackMD 옵션보다 먼저 읽습니다.
  • marsdawn export --breaks는 HackMD처럼 문단 안의 모든 줄바꿈을 줄바꿈으로 표시합니다. 주지 않으면 중국어나 일본어 글자 두 개 사이의 줄바꿈은 없어져 앞뒤 줄이 한 문장으로 이어집니다. 한국어는 단어를 띄어 쓰므로 공백을 유지합니다.
  • 아주 큰 문서에는 미리보기와 내보낸 PDF 모두에 상한이 있습니다. 128K자를 넘는 코드 블록은 구문 강조를 하지 않고, 합계 256K자를 넘으면 구문 강조를 멈춥니다. 한 번 업데이트할 때 Mermaid 다이어그램은 100개, 수식은 1,000개까지 렌더링합니다. 나머지 다이어그램은 전에 그린 적이 있더라도 안내와 함께 소스를 보여 줍니다.
  • 시퀀스 다이어그램에서 rect 블록 안의 메시지 레이블 둘레가 그 블록의 색이 됩니다.
  • 표 바로 위에 각주 참조가 있어도 marsdawn export가 더 이상 비정상 종료되지 않습니다.
  • marsdawn skill --install은 폴더를 만들 수 없거나 파일을 쓸 수 없을 때 코드 7(skill_install_failed)로 종료합니다. 기존 SKILL.md는 그대로 둡니다.

marsdawn 0.6.4

2026년 10월 13일. 접을 수 있는 <details> 블록.

  • GitHub 방식의 <details> 블록은 안에 빈 줄이 있어도 접을 수 있는 하나의 요소로 렌더링됩니다. 미리보기와 내보낸 PDF 모두 같습니다. 이전에는 첫 빈 줄에서 나뉘었습니다.
  • PDF로 내보낼 때는 인쇄하기 전에 모든 <details> 블록을 펼칩니다(front matter 제외).
  • <details> 블록을 펼치거나 접어도 미리보기의 스크롤 위치가 그대로 유지됩니다.

marsdawn 0.6.3

2026년 10월 6일. MarsDawn이 Mac App Store에 출시되었습니다.

  • 앱이 설치되어 있지 않으면 marsdawn open이 Mac App Store의 MarsDawn을 안내합니다.
  • README와 에이전트 스킬에서 marsdawn open .과 --folder 사용법을 안내합니다. MarsDawn 1.0.0은 윈도우의 사이드바에 폴더를 보여줍니다.

marsdawn 0.6.1

2026년 9월 29일. 테마 확인.

  • marsdawn theme validate는 앱과 같은 규칙으로 theme.json을 확인합니다. 테마가 올바르면 코드 0, 아니면 코드 1로 종료하며 문제를 하나씩 보여 줍니다. --require-complete를 주면 구문 강조와 다이어그램 색상도 요구합니다.
  • marsdawn theme css는 올바른 테마에 대해 미리보기가 쓰는 CSS를 출력하고, marsdawn theme preview는 그 테마로 샘플 문서를 라이트나 다크 PNG로 렌더링합니다.

marsdawn 0.5.4

2026년 9월 26일. Mermaid 수정, 다이어그램 오류의 줄 번호, 스킬 설치.

  • 시퀀스 다이어그램에서 다른 참여자의 생명선을 가로지르는 메시지 레이블이 미리보기와 내보낸 PDF 모두에서 읽기 쉽게 유지됩니다.
  • marsdawn export가 Mermaid 다이어그램이 가득한 문서도 처리합니다. 예전에는 종료 코드 5로 실패하던 다이어그램 50개짜리 문서도 이제 내보내집니다.
  • marsdawn export --json에 diagramErrorDetails가 추가되어 다이어그램 오류마다 줄 번호를 알려줍니다. 문서에서 다이어그램이 시작하는 위치와, Mermaid가 지목하는 경우 오류가 난 줄 자체입니다.
  • marsdawn skill --install은 Claude Code용 에이전트 스킬을 ~/.claude/skills/marsdawn/SKILL.md에, 또는 --dir로 지정한 다른 폴더에 설치합니다. 같은 파일이 있으면 그대로 두고, 다른 파일은 --force를 줄 때만 바꿉니다. 그렇지 않으면 종료 코드 64(skill_differs)로 끝나며 아무것도 바꾸지 않습니다.

marsdawn 0.5.3

2026년 9월 25일. 폴더 상태, Mermaid 오류 전문, 작은 수정들.

  • marsdawn open --folder가 폴더에 어떤 일이 있었는지 알려줄 수 있습니다. 응답을 보내는 앱이라면 최대 --wait초(기본값 2초) 동안 기다리고, --json은 attached나 needsUser 같은 상태를 돌려줍니다.
  • 파싱되지 않는 Mermaid 다이어그램은 오류 메시지의 첫 줄만이 아니라 Mermaid의 오류 메시지 전체를 보여주며, 줄 번호는 문서 맨 위부터 셉니다.
  • 프런트 매터 블록의 끝을 찾는 검색이 1,000줄에서 멈추므로, 닫히지 않은 블록 때문에 큰 문서의 나머지를 끝까지 훑는 일이 더는 없습니다.
  • 앱이 PDF 내보내기와 프린트용으로 각주 되돌아가기 링크에 번역된 레이블을 붙일 수 있습니다. 이 레이블은 페이지에 인쇄되지 않으며, marsdawn export는 영어 레이블을 유지합니다.
  • 함께 들어 있는 highlight.js가 이제 KaTeX, Mermaid처럼 버전, 출처, SHA-256으로 고정됩니다.

marsdawn 0.5.2

2026년 9월 24일. 각주, 대비, 폴더.

  • 내보낸 PDF에 각주가 표시됩니다. 번호가 붙은 참조가 들어가고, 주석은 본문 뒤에 옵니다.
  • 모든 테마가 라이트와 다크 모두에서 WCAG AA 대비 기준을 충족합니다. 클래식은 이제 흑백입니다.
  • marsdawn skill은 설치된 marsdawn에 맞는 에이전트 스킬을 출력합니다.
  • marsdawn open은 찾은 MarsDawn이 폴더를 보여줄 수 없을 때 성공을 보고하는 대신 종료 코드 6(app_cannot_open_folders)으로 끝납니다.
  • 내보낸 페이지에 그려지는 자리 표시자가 독일어, 프랑스어, 스페인어, 한국어로도 나옵니다.
  • 이미지 자리 표시자가 아주 긴 상대 경로 뒤에 있는 절대 경로를 더는 보여주지 않습니다.
  • MARSDAWN_APP_PATH는 MarsDawn 앱을 가리킬 때만 사용됩니다.

marsdawn 0.5.1

2026년 9월 19일. PDF 내보내기와 명령줄에서 파일 열기.

  • 내보낸 PDF의 텍스트 레이어가 중국어, 일본어, 한국어에서 바르게 고쳐졌습니다.
  • marsdawn open --background는 MarsDawn을 앞으로 가져오지 않고 파일을 엽니다.
  • marsdawn open에 폴더를 줄 수 있으며, MarsDawn이 그 폴더를 윈도우의 사이드바에 보여줍니다(MarsDawn 1.0.0 이상).
