MarsDawn을 사용하려면 무엇이 필요합니까?

macOS 26 Tahoe 이상이 설치된 Apple 실리콘 또는 Intel 기반 Mac이 필요합니다.

편집기와 미리보기는 어떻게 전환합니까?

⌘1을 누르면 소스만, ⌘2를 누르면 나란히, ⌘3을 누르면 미리보기만 표시됩니다. 같은 선택 항목이 보기 메뉴와 도구 막대에도 있습니다.

문서의 이미지가 표시되지 않습니다.

  • Mac에 있는 이미지: 먼저 문서를 저장한 다음, 미리보기에서 *폴더 접근 허용…*을 클릭하고 이미지가 있는 폴더를 선택하십시오. MarsDawn이 그 폴더를 기억합니다. 접근을 허용한 폴더는 MarsDawn › 설정 › 폴더 접근에서 확인할 수 있습니다.
  • 웹 이미지: 웹 이미지는 미리보기 상단의 이미지 불러오기를 클릭할 때까지 차단됩니다. 항상 불러오려면 설정에서 원격 이미지 자동으로 불러오기를 켜십시오.

이미지는 어떻게 추가합니까?

편집기로 드래그하거나 붙여넣으십시오. 먼저 문서를 저장해야 합니다. MarsDawn이 문서 옆의 assets 폴더에 이미지를 복사하고 Markdown 링크를 대신 작성합니다.

Mermaid 다이어그램에 오류가 표시됩니다.

MarsDawn은 다이어그램의 소스를 보여주고, 그 아래에 Mermaid 오류 메시지의 첫 줄을 표시합니다. 메시지가 가리키는 줄을 확인하십시오. 예를 들어 화살표 뒤에 아무것도 없거나 괄호가 닫히지 않았을 수 있습니다.

PDF는 어떻게 만듭니까?

파일 › PDF로 내보내기…(⌥⌘E)를 선택하십시오. PDF는 미리보기 테마의 라이트 버전을 사용하며, 어떤 레이아웃을 쓰고 있든 페이지로 나뉩니다. 파일 › 프린트…로 같은 페이지를 프린트할 수 있습니다.

Siri나 단축어에서 MarsDawn을 어떻게 사용합니까?

단축어 앱을 열고 MarsDawn을 검색하면 새로운 Markdown 문서, 수신함에 메모 추가, 최근 사용한 문서 열기를 찾을 수 있습니다. 메모를 추가하기 전에 MarsDawn › 설정 › 메모 폴더에서 메모 폴더를 선택하십시오. 메모는 그 폴더의 Inbox.md에 추가됩니다.

설정은 어디에 있습니까?

MarsDawn › 설정(⌘,)에서 화면 모드, 이미지, 메모 폴더, 폴더 접근 및 미리보기 테마를 설정할 수 있습니다.

환불은 어떻게 받습니까?

구입은 Apple이 처리합니다. reportaproblem.apple.com에서 환불을 요청하십시오.
