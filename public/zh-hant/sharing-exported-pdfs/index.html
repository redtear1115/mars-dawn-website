把 PDF 交出去，不是把 Markdown 交出去。

agent 寫完一份文件，你審閱、修改過後，公司裡不寫程式的人也要看——主管、客戶，或另一個團隊的人。他們不需要知道 ## 或表格的直線符號是什麼意思。輸出成 PDF，交給他們那份就好。

把審閱過的文件輸出成 PDF，傳那個檔案就好。它在任何地方都打得開，不需要懂 Markdown，也不用安裝任何東西，看起來就跟你在預覽裡看到的一樣——圖表、表格、格式都在。

為什麼不直接傳 .md 檔案

用純文字編輯器打開 .md 檔案，看到的是記號，不是排好版的頁面：# 是標題，** 包住粗體文字，圍住 Mermaid 圖表的程式碼區塊沒有畫出圖。不寫 Markdown 的人看不出這些記號原本要呈現什麼，而為了一份文件就要對方先裝一個檢視器，也要求太多。

為什麼不直接傳截圖

截圖只能定格文件的其中一畫面，文件可能有好幾頁，內容不能搜尋也不能選取，轉傳個幾次、被壓縮後也會更難讀。PDF 不管文件多長，都能保留文字、圖表和分頁。

PDF 能給你什麼

  • 對方已經有的東西就能打開——Preview、瀏覽器、Acrobat、手機都行，不需要任何 Markdown 工具。
  • Mermaid 圖表會畫出來，不會留著程式碼原樣；程式碼區塊保留語法上色。
  • 分頁位置經過安排，標題不會孤零零留在頁尾，表格或圖表也不會被切成兩半。
  • 不管是從 MarsDawn app 還是免費的命令列輸出，得到的都是同一份檔案——完整步驟請看Markdown 轉 PDF。
