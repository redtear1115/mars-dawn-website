## 3. 我改寫的地方（不是逐字對）

- **zh-hans：** 照 zh-Hant 的結構，詞換成簡體 App 用語：区块、默认、可折叠区块、附注。
- **ja：** 「にも対応しています」（頁面前文已用「対応しています」）；「色付きのバー」；デフォルト（macOS 日文用語）；「終わりの `:::`」。inline code 和日文之間留半形空格，跟頁面其他句一致。
- **ko：** 合니다體；「닫는 `:::` 줄」避開「`:::`가／이」的助詞選擇。
- **de：** 英文那句太長，拆成兩句（標題預設值一句、自訂標題一句）；「reduzierbarer Block」跟 App 選單「Format ▸ Reduzierbarer Block」同詞（CLI 說明裡的「ausklappbar」是描述語，這裡不用）；du 形。
- **fr：** vous 形；撇號用 ’（U+2019），跟頁面其他句一致；這一句沒有 `:`、`;`、`?`、`!`，所以不需要 U+00A0。
- **es：** tú 形；「al hacer clic」「barra de color」。

檢查（程式）：六語的 inline code 順序和 en 完全相同（`:::`、`:::info`、`:::success`、`:::warning`、`:::danger`、`:::spoiler`、`:::`、`:::`）；每語都含 kit 的四個預設標題；沒有【待定】、沒有破折號、沒有 U+00A0；fr 的撇號全是 ’。
