在访达用快速查看预览 Markdown。

在访达选取 Markdown 文件，按空格键。装了 MarsDawn 之后，快速查看显示的是排版后的页面，不是纯文本。

预览会显示什么

  • 排版后的页面，和 MarsDawn 预览窗格用的是同一个渲染器。
  • Mermaid 图表、KaTeX 数学公式和高亮的代码块。
  • 你在 MarsDawn 里选的预览主题，浅色或深色。
  • 网络图片依然会被拦下，放在文件旁边的图片也可能只显示占位图标。

如何用快速查看预览 Markdown 文件

  1. 安装 MarsDawn。 从 Mac App Store 下载 MarsDawn。快速查看扩展是 app 的一部分。
  2. 选取 Markdown 文件。 在访达点一下 .md 文件。
  3. 按空格键。 排版后的预览会打开，再按一次空格键就会关闭。
  4. 看到纯文本的话，把扩展打开。 打开“系统设置”，前往“通用”▸“登录项与扩展”，点按“扩展”下“快速查看”旁边的信息按钮，打开“MarsDawn Preview”，然后点按“完成”。

不受试用期限制

试用期结束后，快速查看照常可用。试用中、试用结束后、解锁之后，它显示的都是同一份排版预览。试用结束、尚未解锁时，只有 MarsDawn 自己的窗口会遮住内容；访达里的预览不变。试用与解锁页面把三个阶段并排列了出来。

常见问题

怎么在访达预览 Markdown 文件？

选取文件后按空格键。装了 MarsDawn，快速查看会显示排版后的页面，包含 Mermaid 图表、KaTeX 数学公式和代码高亮。

14 天试用结束后，快速查看还能用吗？

能。快速查看不受试用期限制，试用中、试用结束后与解锁之后都会继续渲染 Markdown 文件。

为什么快速查看只显示纯文本？

可能是快速查看扩展没有打开。打开“系统设置”，前往“通用”▸“登录项与扩展”，点按“扩展”下“快速查看”旁边的信息按钮，打开“MarsDawn Preview”，然后点按“完成”。

快速查看要另外付费吗？

不用。快速查看扩展是 MarsDawn 的一部分，没有另外的购买。MarsDawn 免费下载，14 天试用，之后一次 USD 4.99 解锁；快速查看不论有没有试用都能用。

需要哪个版本的 macOS？

MarsDawn 需要 macOS 26 或更新版本。
