Markdown 명세서(PRD) 템플릿

에이전트가 채우고 여러분이 한 번에 읽을 수 있는 명세서입니다. 문제, 목표, 요구 사항, 흐름도, 인수 기준으로 이루어져 있습니다. 요구 사항을 바꿨다면 나머지를 맞춰 달라고 에이전트에게 요청하세요.

# 명세: 로그인 코드 ## 요구 사항 - R1: 6자리 코드를 메일로 보낸다. - R2: 코드는 10분 후 만료. - R3: 2단계 인증을 요구한다. ## 흐름 ```mermaid flowchart LR A[이메일] --> B[코드] B --> C[2단계 인증] CB --> D[로그인 완료] ``` ## 인수 기준 - [ ] R1: 1분 안에 코드 도착. - [ ] R3: 기기당 한 번만.
명세: 로그인 코드

이메일→코드→2단계 인증→로그인 완료

  • R3: 기기당 한 번만.
› marsdawn open spec.md
› R3를 뺐어요. 흐름과 인수 기준을 맞춰 주세요.
완료했어요. 흐름에서 2단계 인증을 건너뛰고, R3 확인 항목도 지웠어요.

spec.md 다운로드

# 명세: 기능 이름

상태: 초안 · 담당: 이름 · 업데이트: 날짜

## 문제

_지금 무엇이 문제인지, 누구에게 문제인지, 어떻게 알게 됐는지._

## 목표

- _출시되면 달라져 있을 것._

## 하지 않을 것

- _이번에 일부러 하지 않는 것._

## 요구 사항

| ID | 요구 사항 | 우선순위 |
|----|-----------|----------|
| R1 | _요구 사항_ | 필수 |
| R2 | _요구 사항_ | 권장 |

## 흐름

```mermaid
flowchart LR
  A[시작] --> B[단계] --> C[결과]
```

## 인수 기준

- [ ] R1: _확인 방법._
- [ ] R2: _확인 방법._

## 미결 질문

- _질문._

보이는 모습

marsdawn export spec.md로 내보냈습니다. 무료 명령줄 도구는 다이어그램을 포함해 MarsDawn의 미리 보기와 똑같이 렌더링합니다.

에이전트에게 맡기기

https://marsdawn.southern-light.dev/ko/templates/spec/spec.md 템플릿을 사용해 [기능]의 명세를 spec.md에 작성해 주세요. 모든 요구 사항에 ID를 붙이고, 흐름도와 인수 기준에서도 같은 ID를 사용해 주세요. 다 쓰면 marsdawn open spec.md를 실행해 주세요.

PDF로 공유하기

marsdawn export spec.md를 실행하면 옆에 spec.pdf가 생깁니다. Markdown을 읽지 않는 사람에게 건네세요.

하지 않는 일

MarsDawn은 명세, 표, 다이어그램을 보여 줍니다. 인수 기준이 모든 요구 사항을 빠짐없이 다루는지는 확인하지 않습니다. 그것은 에이전트의 일이고, 여러분이 읽으며 확인할 일입니다.

자주 묻는 질문

흐름도를 그리려면 무언가를 설치해야 하나요?

아니요. MarsDawn과 marsdawn export가 Mermaid를 직접 그리며, 오프라인에서도 됩니다.

MarsDawn에서 명세를 편집할 수 있나요?

네. 소스 옆에 미리 보기가 있는 Markdown 편집기입니다. 에이전트는 다음에 파일을 읽을 때 여러분의 수정 내용을 보게 됩니다.
