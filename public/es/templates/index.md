# Plantillas de Markdown

Para los documentos que escribe un agente y lees tú. Cada plantilla incluye un prompt para tu agente. Abre el archivo completado en MarsDawn para leer lo que escribió.

- [Especificación (PRD)](/es/templates/spec/): problema, objetivos, requisitos, un diagrama del flujo y criterios de aceptación.
- [Diagrama de flujo](/es/templates/flowchart/): un diagrama Mermaid con los pasos escritos debajo.
- [Minuta de reunión](/es/templates/meeting-notes/): decisiones y tareas, cada una con un responsable.
