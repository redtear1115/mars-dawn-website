HackMD から Mac へ

ノートはもともと Markdown なので、変換はいりません。移す量に合わせて、方法を選んでください。画像は別の作業が必要です。HackMD の内容を削除する前に「画像」の節を読んでください。

このページは、2026年11月に HackMD の無料アカウントで確かめた内容です。HackMD は変わることがあります。有料プランとチームワークスペースは試していません。

やりたいこと方法
ノートをすべて移すすべてのノートをダウンロード
GitHub にあるノートを移すリポジトリを clone
1、2 件だけ移す1 件ずつダウンロード

すべてのノートをダウンロード

HackMD のノート設定に Download all notes があります。個人とチームのどちらのワークスペースでも使えます。ノートごとの .md が 1 つの .zip にまとまり、ファイル名はノートのタイトルになります。

  • フォルダは保たれません。すべてのノートが最上位に入ります。
  • 画像は含まれません。.md の中は URL のままです。
  • タイトルとタグを含めるオプションは初期状態でオンで、各ノートの先頭に front matter を追加します。オフにすると、ノートの原文のままになります。

展開したら、MarsDawn で「ファイル ▸ フォルダを開く…」を選び、そのフォルダを開きます。

リポジトリを clone

HackMD の GitHub 同期は 1 つのノートを 1 つのファイルに対応させます。プッシュ済みのノートは、すでにリポジトリにあります。clone して「ファイル ▸ フォルダを開く…」で開くと、サイドバーにリポジトリとブランチが表示されます。

まだ GitHub につないでいないノートは、移行のためにつなぐ必要はありません。ノートごとに設定が必要で、無料プランのプッシュは月 20 回までです。無料の個人アカウントでは、ワークスペース全体を一度にプッシュする入口は見当たりませんでした。

移行したあとは、リポジトリを正本にしてください。HackMD からプッシュすると、GitHub の内容をそのまま上書きします。GitHub のほうが新しくても同じで、警告は出ません。

1 件ずつダウンロード

ノートのメニューから .md か .html をダウンロードできます。.md を選び、MarsDawn で開きます。

画像

HackMD にアップロードした画像の URL は https://hackmd.io/_uploads/... です。誰が見られるかは、ノートの権限に従います。

ノートMac に移したあと対処
公開画像は HackMD から読み込まれますプレビューで「イメージを読み込む」をクリックするか、「設定 ▸ イメージ ▸ リモートイメージを自動的に読み込む」をオンにします
非公開MarsDawn は HackMD にログインしていないので、画像はエラーになりますログインしたブラウザで画像を保存し、.md の横に置いてパスを書き換えます。全員に見られてもよければ、ノートを公開にする方法もあります
  • 古いノート の画像は i.imgur.com の URL のことがあります。
  • ノートを削除すると、画像も使えなくなります。 URL が開けなくなるので、画像を移してから削除してください。

ファイルの横の画像を MarsDawn が読めないときは、プレビューのボタンでそのフォルダへのアクセスを許可します。

ノートの見え方

HackMD の記法はほとんどそのまま読めます。==ハイライト==、^上付き^、~下付き~、[TOC]、=300x200 のような画像サイズ、Mermaid、KaTeX に対応しています。{%youtube %} はリンクになります。HackMD と同じようにすべての改行を保つには、「設定 ▸ 外観モード ▸ 単一の改行を保持」をオンにします。

::: ブロックにも対応しています。:::info、:::success、:::warning、:::danger は、色付きのバーと見出しが付いたブロックとして表示されます。見出しのデフォルトはメモ、ヒント、警告、危険で、名前のあとに自分で見出しを書けば、その見出しが使われます。:::spoiler は、クリックすると開く折りたたみ可能なブロックとして表示されます。ほかの名前の ::: ブロックや、終わりの ::: がないものは、書いたまま表示されます。

いくつか違う点があります。

  • ++下線++ と :sparkles: のような絵文字コードは、書いたまま表示されます。
  • {%hackmd id %} は展開されません。
  • <i class="fa ..."> のアイコンは表示されません。

スクリプトで：hackmd-cli

hackmd-cli には、すべてを一度に書き出すコマンドはありません。1 回に 1 件を書き出して表示するので、ノートを一覧にしてからループで回します。Node.js、jq、HackMD の設定で作った API トークンが必要です。スクリプトが必要なければ、Download all notes のほうが簡単です。

npm install -g @hackmd/hackmd-cli
export HMD_API_ACCESS_TOKEN=<あなたのトークン>
hackmd-cli notes --output json | jq -r '.[].id' | while read -r id; do
  hackmd-cli export --noteId="$id" > "$id.md"
done
  • フォルダは引き継がれません。 ノートの一覧にはどのフォルダにあるかが含まれないので、ファイルはすべて同じ場所に入ります。
  • 画像は hackmd.io のリンクのままです。 上の「画像」の節のとおりに対処してください。
  • ファイル名はノートの ID です。 タイトルではありません。
  • 無料プランの API は 30 日で 400 回までです。 一覧に 1 回、ノート 1 件ごとに 1 回使います。

ノートが少ないアカウントでしか試していないので、一覧がとても長いときの動きはわかりません。終わったら、HackMD の設定でトークンを削除してください。

一緒に書くなら

MarsDawn に複数人の同時編集はありません。共同で書くなら、HackMD を使い続けてください。チームが書類を git で管理しているなら、それぞれが自分の MarsDawn で同じリポジトリを開いて、ひとつの書類を一緒に仕上げられます。チームで git を使って書類をレビューするをご覧ください。

よくある質問

HackMD のノートをまとめてダウンロードできますか？

はい。Download all notes で、.md が入った .zip を 1 つダウンロードできます。フォルダは保たれず、画像も含まれません。

MarsDawn で画像が表示されないのはなぜですか？

MarsDawn は Web の画像を初期状態では読み込みません。「イメージを読み込む」をクリックしてください。非公開のノートの画像は読み込めないので、ファイルの横に保存してください。

HackMD をやめる必要はありますか？

ありません。一緒に書くなら、HackMD のほうが向いています。MarsDawn は Mac で読んでレビューするためのアプリです。
