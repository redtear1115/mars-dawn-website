Markdown 範本

給 agent 寫、你來讀的文件。每份範本都附一段給 agent 的提示詞。把填好的檔案用 MarsDawn 打開，讀讀它寫了什麼。

  • 規格文件（PRD）：問題、目標、需求、流程圖和驗收條件。
  • 流程圖：一張 Mermaid 圖，下方把每個步驟寫出來。
  • 會議記錄：決議和行動項目，每項都有負責人。
