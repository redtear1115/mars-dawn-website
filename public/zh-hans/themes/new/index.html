打造一个主题

在下面挑一组色板和几个样式选项。右边的范例文档会实时更新，同时有浅色和深色两种，主题图库 CI 会做的每一项检查也会显示在这里——所以送出投稿 issue 的主题，通常已经先过关了。

投稿需要一个 GitHub 账号。这个页面本身不用安装，也不用 git。

AI 代理可以替你写主题文件：看看和代理一起做主题，再把它给你的链接在这里打开来调整。

这个页面需要 JavaScript 才能建立与预览主题。
