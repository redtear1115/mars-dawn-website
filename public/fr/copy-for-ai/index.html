Donnez à votre agent le chemin, les numéros de ligne et le texte

Copier pour l’IA copie votre sélection avec son chemin de fichier et ses numéros de ligne, sans IDE ni plug-in. Collez-la dans n’importe quel agent.

Ce que vous collez :

docs/plan.md:42-43
```markdown
Réessayer trois fois après un échec.
Puis afficher la dernière copie.
```

Comment l’utiliser

  1. Sélectionnez du texte dans la source, en Source uniquement ou Partagé. Sans sélection, la ligne du curseur est copiée.
  2. Choisissez Édition ▸ Copier pour l’IA, appuyez sur ⌃⌥⌘C, ou faites un clic secondaire sur la sélection.
  3. Collez-la dans le chat de votre agent.

À quoi ressemble le chemin

Dans un checkout Git accessible à MarsDawn, ou un dossier de la barre latérale, le chemin est relatif au projet. Ailleurs, c’est le chemin complet, qui peut montrer votre nom d’utilisateur. Dans un worktree, le sous-titre de la fenêtre indique la branche si MarsDawn peut lire le dépôt principal.
