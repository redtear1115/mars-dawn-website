Give your agent the file path, line numbers and text

Copy for AI copies your selection with its file path and line numbers, with no IDE or plugin. Paste it into any agent.

What you paste:

docs/plan.md:42-43
```markdown
Retry a failed upload three times.
Then show the last saved copy.
```

How to use it

  1. Select text in the source, in Source Only or Split. With nothing selected, the line the cursor is on is copied.
  2. Choose Edit ▸ Copy for AI, press ⌃⌥⌘C, or Control-click the selection.
  3. Paste it into your agent's chat.

Copy for AI or Send to…

Copy for AISend to…
ResultOn the clipboard, for you to pasteOpens Claude or ChatGPT with a prompt
PathRelative in a project, full path outside oneRelative path or file name, never a full path
Who answersThe agent you paste intoThe service you pick

What the path looks like

In a Git checkout MarsDawn can access, or a sidebar folder, the path is relative to the project. Elsewhere it's the full path, which can show your user name. In a worktree, the sidebar shows the branch once the main repo folder has access too.
