# Markdown meeting notes template

Decisions first, then action items, each with an owner. Let your agent write the notes from the transcript, and read them before they go out. When a decision changes, ask the agent to bring the action items in line.

## The template

[Download meeting-notes.md](/templates/meeting-notes/meeting-notes.md)

```
# Meeting name, date

Attendees: _names_

## Decisions

- _What was decided, in one line each._

## Action items

- [ ] Name: _what, by when._
- [ ] Name: _what, by when._

## Notes

- _Anything worth keeping that isn't a decision or an action._
```

## Ask your agent

```
Write up this meeting in meeting-notes.md, using the template at https://marsdawn.southern-light.dev/templates/meeting-notes/meeting-notes.md. Decisions first, one line each; every action item gets one owner and a date. When it's written, run marsdawn open meeting-notes.md.
```

## Share it as a PDF

`marsdawn export meeting-notes.md` writes a PDF you can attach to the follow-up mail.

## What it doesn't do

MarsDawn doesn't record or transcribe the meeting, and it doesn't track the action items. It shows the notes as they'll be read.

## Questions

### Do the checkboxes work?

They show as checkboxes in the preview and the PDF. Tick one by changing `[ ]` to `[x]` in the source.

### Can the agent keep the notes and the action items in step?

Yes, that's the point of the loop: change one, and ask it to update the rest. MarsDawn shows you the result.
