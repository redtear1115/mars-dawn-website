在 Finder 用快速查看預覽 Markdown。

在 Finder 選取 Markdown 檔案，按空白鍵。裝了 MarsDawn 之後，快速查看顯示的是排版後的頁面，不是純文字。

預覽會顯示什麼

  • 排版後的頁面，和 MarsDawn 預覽窗格用的是同一個轉譯器。
  • Mermaid 圖表、KaTeX 數學式和上色的程式碼區塊。
  • 你在 MarsDawn 選的預覽主題，淺色或深色。
  • 網路圖片依然會被擋下，放在檔案旁邊的圖片也可能只顯示佔位圖示。

如何用快速查看預覽 Markdown 檔案

  1. 安裝 MarsDawn。 從 Mac App Store 下載 MarsDawn。快速查看擴充功能是 app 的一部分。
  2. 選取 Markdown 檔案。 在 Finder 點一下 .md 檔案。
  3. 按空白鍵。 排版後的預覽會打開，再按一次空白鍵就會關閉。
  4. 看到純文字的話，把擴充功能打開。 打開「系統設定」，前往「一般」▸「登入項目與延伸功能」，按一下「延伸功能」下「快速查看」旁的資訊按鈕，打開「MarsDawn Preview」，再按一下「完成」。

不受試用期限制

試用期結束後，快速查看照常可用。試用中、試用結束後、解鎖之後，它顯示的都是同一份排版預覽。試用結束、尚未解鎖時，只有 MarsDawn 自己的視窗會遮住內容；Finder 裡的預覽不變。試用與解鎖頁面把三個階段並排列了出來。

常見問題

怎麼在 Finder 預覽 Markdown 檔案？

選取檔案後按空白鍵。裝了 MarsDawn，快速查看會顯示排版後的頁面，包含 Mermaid 圖表、KaTeX 數學式和程式碼上色。

14 天試用結束後，快速查看還能用嗎？

能。快速查看不受試用期限制，試用中、試用結束後與解鎖之後都會繼續轉譯 Markdown 檔案。

為什麼快速查看只顯示純文字？

可能是快速查看擴充功能沒有打開。打開「系統設定」，前往「一般」▸「登入項目與延伸功能」，按一下「延伸功能」下「快速查看」旁的資訊按鈕，打開「MarsDawn Preview」，再按一下「完成」。

快速查看要另外付費嗎？

不用。快速查看擴充功能是 MarsDawn 的一部分，沒有另外的購買。MarsDawn 免費下載，14 天試用，之後一次 USD 4.99 解鎖；快速查看不論有沒有試用都能用。

需要哪個版本的 macOS？

MarsDawn 需要 macOS 26 或更新版本。
