把檔案路徑、行號和內容一起交給 agent

「拷貝給 AI」會把選取的文字連同檔案路徑和行號一起拷貝，不用開 IDE，也不用裝外掛。貼進任何 agent 就好。

貼上後長這樣：

docs/plan.md:42-43
```markdown
上傳失敗時重試三次。
之後顯示上次儲存的版本。
```

怎麼用

  1. 在原始碼裡選取文字，用「只顯示原始碼」或「並排」都可以。沒有選取時，會拷貝游標所在的那一行。
  2. 選「編輯 ▸ 拷貝給 AI」、按 ⌃⌥⌘C，或在選取的文字上按右鍵。
  3. 貼到 agent 的對話裡。

「拷貝給 AI」和「傳給⋯」的差別

拷貝給 AI傳給⋯
結果放到剪貼簿，由你貼上帶著提示打開 Claude 或 ChatGPT
路徑專案內是相對路徑，專案外是完整路徑相對路徑或檔名，不會是完整路徑
誰回答你貼給的 agent你選的服務

路徑長什麼樣

檔案在 MarsDawn 可存取的 git checkout 或側邊欄資料夾裡，路徑相對於專案。其他是完整路徑，可能帶出使用者名稱。主 repo 可讀取時，worktree 的分支顯示在視窗副標題。
