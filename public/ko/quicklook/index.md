# Finder의 훑어보기로 Markdown 미리보기.

Finder에서 Markdown 파일을 선택하고 스페이스 바를 누르세요. MarsDawn이 설치되어 있으면 훑어보기(Quick Look)가 일반 텍스트 대신 렌더링된 페이지를 보여 줍니다.

## 미리보기에 보이는 것

- MarsDawn의 미리보기 패널과 같은 렌더러로 그린 렌더링된 페이지.
- Mermaid 다이어그램, KaTeX 수식, 강조된 코드 블록.
- MarsDawn에서 고른 미리보기 테마(라이트 또는 다크).
- 웹 이미지는 계속 차단되며, 파일 옆에 있는 이미지는 자리 표시자로 나타날 수 있습니다.

## 훑어보기로 Markdown 파일을 미리 보는 방법

1. **MarsDawn을 설치하세요.** Mac App Store에서 MarsDawn을 다운로드하세요. 훑어보기 확장 프로그램은 앱의 일부입니다.
2. **Markdown 파일을 선택하세요.** Finder에서 .md 파일을 한 번 클릭하세요.
3. **스페이스 바를 누르세요.** 렌더링된 미리보기가 열립니다. 스페이스 바를 다시 누르면 닫힙니다.
4. **일반 텍스트가 보이면 확장 프로그램을 켜세요.** 시스템 설정을 열고 일반 ▸ 로그인 항목 및 확장 프로그램으로 이동한 다음, 확장 프로그램 아래 ‘훑어보기’ 옆의 정보 버튼을 클릭하고 ‘MarsDawn Preview’를 켠 뒤 완료를 클릭하세요.

## 체험 기간의 제한을 받지 않습니다

훑어보기는 체험이 끝난 뒤에도 계속 작동합니다. 체험 중에도, 체험이 끝난 뒤에도, 잠금을 해제한 뒤에도 같은 렌더링된 미리보기를 보여 줍니다. 체험이 끝나고 잠금을 해제하기 전까지는 MarsDawn 자체의 윈도우만 내용이 가려지고, Finder의 미리보기는 그대로입니다. [체험과 잠금 해제 페이지](/ko/pay-once/)에서 세 단계를 나란히 볼 수 있습니다.

## 자주 묻는 질문

### Finder에서 Markdown 파일을 미리 보려면 어떻게 하나요?

파일을 선택하고 스페이스 바를 누르세요. MarsDawn이 설치되어 있으면 훑어보기가 Mermaid 다이어그램, KaTeX 수식, 강조된 코드를 포함한 렌더링된 페이지를 보여 줍니다.

### 14일 체험이 끝나도 훑어보기를 쓸 수 있나요?

네. 훑어보기는 체험 기간의 제한을 받지 않습니다. 체험 중에도, 체험이 끝난 뒤에도, 잠금을 해제한 뒤에도 Markdown 파일을 계속 렌더링합니다.

### 훑어보기에 일반 텍스트만 보이는 이유는 무엇인가요?

훑어보기 확장 프로그램이 꺼져 있을 수 있습니다. 시스템 설정을 열고 일반 ▸ 로그인 항목 및 확장 프로그램으로 이동한 다음, 확장 프로그램 아래 ‘훑어보기’ 옆의 정보 버튼을 클릭하고 ‘MarsDawn Preview’를 켠 뒤 완료를 클릭하세요.

### 훑어보기는 따로 비용이 드나요?

아니요. 훑어보기 확장 프로그램은 MarsDawn의 일부이며 별도 구입이 필요 없습니다. MarsDawn은 무료로 다운로드할 수 있고, 14일 체험 뒤 잠금 해제는 한 번만 USD 4.99이며, 훑어보기는 체험 여부와 관계없이 작동합니다.

### 어떤 버전의 macOS가 필요한가요?

MarsDawn에는 macOS 26 이상이 필요합니다.
