Finder のクイックルックで Markdown をプレビュー。

Finder で Markdown ファイルを選んでスペースキーを押します。MarsDawn をインストールしていれば、クイックルックはプレーンテキストではなく、描画されたページを表示します。

プレビューに表示されるもの

  • MarsDawn のプレビューペインと同じレンダラーで描画されたページ。
  • Mermaid 図、KaTeX 数式、ハイライトされたコードブロック。
  • MarsDawn で選んだプレビューテーマ（ライトまたはダーク）。
  • Web の画像はブロックされたままで、ファイルの隣にある画像はプレースホルダとして表示されることがあります。

クイックルックで Markdown ファイルをプレビューする方法

  1. MarsDawn をインストールします。 Mac App Store から MarsDawn をダウンロードします。クイックルックの機能拡張はアプリの一部です。
  2. Markdown ファイルを選びます。 Finder で .md ファイルを一度クリックします。
  3. スペースキーを押します。 描画されたプレビューが開きます。もう一度スペースキーを押すと閉じます。
  4. プレーンテキストが表示されたら、機能拡張をオンにします。 「システム設定」を開き、「一般」▸「ログイン項目と機能拡張」に進んで、「機能拡張」の「クイックルック」の横にある情報ボタンをクリックし、「MarsDawn Preview」をオンにして「完了」をクリックします。

トライアル期間の制限を受けません

トライアル終了後も、クイックルックはそのまま使えます。トライアル期間中も、終了後も、ロック解除後も、同じ描画済みのプレビューを表示します。トライアル期間が終わってロックを解除するまでは、MarsDawn 自身のウインドウだけが内容を覆い、Finder のプレビューは変わりません。トライアルとロック解除のページでは、3つの段階を並べて確認できます。

よくある質問

Finder で Markdown ファイルをプレビューするには？

ファイルを選んでスペースキーを押します。MarsDawn をインストールしていれば、クイックルックは Mermaid 図、KaTeX 数式、ハイライトされたコードを含む、描画されたページを表示します。

14日間のトライアルが終わっても、クイックルックは使えますか？

はい。クイックルックはトライアル期間の制限を受けません。トライアル期間中も、終了後も、ロック解除後も、Markdown ファイルを描画し続けます。

クイックルックがプレーンテキストを表示するのはなぜですか？

クイックルックの機能拡張がオフになっている可能性があります。「システム設定」を開き、「一般」▸「ログイン項目と機能拡張」に進んで、「機能拡張」の「クイックルック」の横にある情報ボタンをクリックし、「MarsDawn Preview」をオンにして「完了」をクリックしてください。

クイックルックは別料金ですか？

いいえ。クイックルックの機能拡張は MarsDawn の一部で、別の購入は不要です。MarsDawn は無料でダウンロードでき、14日間試せて、ロック解除は USD 4.99 の一度きりです。クイックルックはトライアルの有無にかかわらず使えます。

必要な macOS のバージョンは？

MarsDawn には macOS 26 以降が必要です。
