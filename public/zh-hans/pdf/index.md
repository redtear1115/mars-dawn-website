# PDF 看起来就是你写的那一页。

输出成 PDF 或打印，使用主题的浅色配色。图表和代码高亮都会保留，分页位置也经过安排。

## 这代表什么

- Mermaid 图表直接画进 PDF。
- 代码块保留语法高亮。
- 分页时会尽量不让标题落在页面底部，也不切开代码、表格和图表。
- 任何布局都能输出，只显示源代码时也可以。

免费的 [marsdawn 命令行工具](/zh-hans/cli/)使用同一套输出程序，所以脚本或 AI agent 也能得到一样的 PDF。
