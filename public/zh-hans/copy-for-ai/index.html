把文件路径、行号和内容一起交给代理

“拷贝给 AI”会把所选文本连同文件路径和行号一起拷贝，不用打开 IDE，也不用装插件。粘贴到任何代理就好。

粘贴后是这样：

docs/plan.md:42-43
```markdown
上传失败时重试三次。
之后显示上次存储的版本。
```

怎么用

  1. 在源代码里选中文本，用“仅显示源代码”或“并排”都可以。没有选中时，会拷贝光标所在的那一行。
  2. 选择“编辑 ▸ 拷贝给 AI”、按 ⌃⌥⌘C，或在选中的文本上点按右键。
  3. 粘贴到代理的对话里。

“拷贝给 AI”和“传给…”的区别

拷贝给 AI传给…
结果放到剪贴板，由你粘贴带着提示打开 Claude 或 ChatGPT
路径项目内是相对路径，项目外是完整路径相对路径或文件名，不会是完整路径
谁回答你粘贴给的代理你选的服务

路径是什么样

文件在 MarsDawn 可访问的 git checkout 或边栏文件夹里，路径相对于项目。其他是完整路径，可能带出用户名。主仓库可读取时，worktree 的分支显示在窗口副标题。
