打造一個主題

在下面挑一組色盤和幾個樣式選項。右邊的範例文件會即時更新，同時有淺色和深色兩種，主題庫 CI 會做的每一項檢查也會顯示在這裡——所以送出投稿 issue 的主題，通常已經先過關了。

投稿需要一個 GitHub 帳號。這個頁面本身不用安裝，也不用 git。

這個頁面需要 JavaScript 才能建立與預覽主題。
