主题库

社区投稿的预览主题，每一个都经过开发者审核、合并后才会出现在这里。按场景筛选，或是在浏览器里打造一个自己的主题——不用安装，也不用 git。

  • Gruvbox v1.0.1 温暖复古的米色、棕色与橘色调色盘 — 改编自 Gruvbox，为可读性调整 技术文档 笔记分享 作者： Southern Light 版权与授权
  • Guide v1.0.1 冷白背景搭配海军蓝标题与清亮蓝色链接，字级加大，适合用户指南、教程与 README 技术文档 作者： Southern Light
  • Ledger v1.0.1 米白纸面、深绿分隔线与实心表头，适合预算、对账单与估价单 正式输出 作者： Southern Light
  • Nord v1.0.1 北欧冰蓝色调，并原创搭配一款浅色版本 — 改编自 Nord，为可读性调整 技术文档 审阅代理产出 作者： Southern Light 版权与授权

  • Spec v1.0.1 白底正文搭配单一砖红强调色，决策与风险以陶土色面板呈现，适合 PRD 与 RFC 审阅代理产出 正式输出 作者： Southern Light
  • Story v1.0.1 亮色便利贴、圆角外观与鲜明任务勾选框，适合用户故事与冲刺笔记 笔记分享 审阅代理产出 作者： Southern Light

版权与授权

Dracula、Nord、Gruvbox 与 Solarized 改编自开源配色项目；每个项目的版权声明与完整授权条文请见第三方授权声明。

主题有问题吗？

用主题卡片上的“举报”按钮（需要 JavaScript），或直接写信到 support@southern-light.dev，附上主题名称和版本——不论有没有 JavaScript 都可以。举报会有人亲自审核，确认属实的主题会在一天内下架。
